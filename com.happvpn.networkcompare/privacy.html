Effective date: 2026-10-05 Application: Happ VPN Network Compare Bundle identifier: com.happvpn.networkcompare Application support/privacy contact: hakangen@proton.me The app publisher is the seller identified on this app's App Store listing. 1. Two declared experiences

The app contains a free native network utility and a separate HTTPS website for a VPN service. The native app has no native in-app purchases and does not itself establish a VPN tunnel. At launch, iOS checks the fixed list of 29 URL schemes on the device. If one can be opened, the app displays the separate service website; otherwise it displays the native utility. This check does not upload a list of installed applications. Both experiences are disclosed in the store description and review instructions.

2. Native records and network requests

Local record content: Labels for two trials, chosen endpoints, HTTP timings and reachability results. Each trial sends five HTTP timing requests to its chosen destination. The destination sees the request and source IP address. Labels and saved comparison records remain on the device unless you share them. Network destinations also receive the technical request/connection information needed to respond, such as the source IP address. Queries sent to a resolver or endpoint are processed by that destination under its policy. Network tests can use mobile data. The app is not a promise of anonymous requests, zero data processing or guaranteed network security.

3. Local storage, sharing and deletion

Saved native records are stored in the iOS application container using local versioned files. The product has no native account-registration or cloud-sync feature for these records. Native HTTP requests use an ephemeral URLSession with cookies and cache disabled. The native implementation includes no advertising or analytics SDK. Use the record's delete action to remove it. The system share sheet sends only what you choose to the receiving app/service; exported copies remain under the recipient's control. Device backups and operating-system data handling follow your Apple/device settings. Removing the app does not erase copies you previously exported or data already processed by a website or network provider. If a saved file cannot be read, the app preserves it instead of silently resetting your records.
