Native workflow

Add an incident, update its state/resolution and filter the timeline. The journal records what you enter; it does not automatically diagnose every network incident. Native interface languages: English and Russian. The primary App Store listing language is tr; listing localization does not imply additional native interface translations.

Why do I see a website at launch?

If iOS can open at least one of the29 declared URL schemes, the app opens the separate VPN-service website through a healthy HTTPS mirror. If none can be opened, it opens the native utility. There is no native/web selector. A native utility app is not itself a system-wide VPN tunnel.

Connection failures

Network checks require a usable connection and an endpoint that accepts the requested operation. Inspect each recorded error rather than treating a failed request as a successful or empty result. The subnet calculator, equipment notebook, incident journal and manual allowance calculations can work locally in their native workflows. If all website mirrors fail, use the displayed Retry action. No continuous background monitoring or automatic system-wide traffic accounting is promised.

Saved records

Use the visible record controls to revisit, edit where provided, delete or share a report. Shared/exported copies are separate from the local original. Unreadable storage is preserved; include the displayed error text when asking for help rather than deleting the app as a first recovery step.

Price and service purchases

The native utility is free and has no native IAP. The separate website can sell its own service under the displayed service terms. The native app does not provide a VPN tunnel merely because VPN is in its name.
